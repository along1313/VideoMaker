# 添加新视频风格操作指南

本文档说明如何在百速AI视频生成系统中添加新的视频风格。

## 概述

视频风格系统允许用户选择不同的图像生成风格来创建具有特定视觉效果的视频。每个风格包含图像生成参数、文本样式和预览图片。

## 操作步骤

### 1. 配置风格参数

编辑 `static/style_config.py` 文件，在 `STYLE_CONFIG` 字典中添加新风格配置：

```python
STYLE_CONFIG = {
    # ... 现有风格 ...
    "新风格名称": {
        "img_generate_system_prompt": "图像生成的提示词，描述风格特征",
        "img_size": "1024x1024",           # 图像尺寸
        "img_resize": 1.0,                 # 图像缩放比例
        "text_color": "white",             # 文本颜色
        "stroke_color": "black",           # 文本描边颜色
        "is_y_slide": True,                # 是否启用垂直滑动效果
    }
}
```

#### 参数说明：

- **img_generate_system_prompt**: AI图像生成的系统提示词，详细描述风格特征
- **img_size**: 生成图像的尺寸，通常为 "1024x1024"
- **img_resize**: 图像在视频中的缩放比例 (0.1-2.0)
- **text_color**: 视频文本颜色，常用 "white" 或 "black"
- **stroke_color**: 文本描边颜色，可为 None 或颜色值
- **is_y_slide**: 是否启用垂直滑动动画效果

### 2. 添加预览图片

在 `static/img/` 目录下放置风格预览图片：

```
static/img/新风格名称.png
```

**图片要求：**
- 文件名必须与风格名称完全一致
- 格式：PNG
- 建议尺寸：200x150 像素
- 文件大小：建议小于 500KB
- 内容：展示该风格的典型视觉效果

### 3. 更新任务编辑界面

编辑 `templates/generate.html` 文件，在风格选择下拉框中添加新选项：

```html
<el-select v-model="editingTask.style" placeholder="请选择风格">
    <!-- 现有选项 -->
    <el-option label="新风格名称" value="新风格名称"></el-option>
</el-select>
```

**位置：**在现有 `<el-option>` 列表的末尾添加

### 4. 验证配置

运行以下命令验证新风格配置是否正确：

```bash
# 检查风格是否在配置中
python -c "from static.style_config import STYLE_CONFIG; print('新风格名称' in STYLE_CONFIG)"

# 查看风格配置详情
python -c "from static.style_config import STYLE_CONFIG; import json; print(json.dumps(STYLE_CONFIG['新风格名称'], indent=2, ensure_ascii=False))"

# 检查预览图片是否存在
ls -la static/img/新风格名称.png
```

### 5. 测试功能

1. **启动应用**：`python run.py`
2. **检查首页**：风格选择区域应自动显示新风格（带预览图）
3. **检查任务管理页面**：编辑任务时下拉框应包含新风格选项
4. **生成测试视频**：使用新风格生成一个测试视频，验证效果

## 自动化机制

### 首页风格显示

首页的风格选择区域会**自动**包含新风格，无需手动修改。这是通过 `app.py` 中的以下代码实现的：

```python
@app.route('/')
def index():
    styles = {}
    for style_name in STYLE_CONFIG.keys():
        style_img = f"/static/img/{style_name}.png"
        styles[style_name] = style_img
    return render_template('index.html', styles=styles)
```

## 风格设计建议

### 提示词编写

1. **具体描述**：明确指出风格的视觉特征
2. **技术参数**：包含色彩、构图、质感等要素
3. **排除项**：使用 `--no` 参数排除不需要的元素
4. **一致性**：确保生成的图像风格统一

### 参数调优

- **img_resize**: 
  - 0.4-0.6：小图片，适合简洁风格
  - 1.0：标准尺寸，适合大部分风格
  - 1.2-1.5：大图片，适合需要突出视觉的风格

- **文本配色**：
  - 浅色背景风格：使用深色文字
  - 深色背景风格：使用浅色文字
  - 高对比度风格：添加描边增强可读性

## 常见问题

### Q: 新风格不显示在首页？
A: 检查预览图片是否存在且命名正确，确保 `static/img/风格名称.png` 文件存在。

### Q: 任务编辑页面没有新风格选项？
A: 检查是否在 `templates/generate.html` 中正确添加了 `<el-option>` 标签。

### Q: 生成的图片风格不符合预期？
A: 优化 `img_generate_system_prompt` 提示词，增加更具体的风格描述。

### Q: 图片尺寸不合适？
A: 调整 `img_resize` 参数，测试不同的缩放比例。
